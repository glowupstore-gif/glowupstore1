# Glow Up Boutique

o nome da loja vai ser Glow Up Store, queria seguir uma linha mais sofisticada e moderna, usando principalmente a paleta de cores: preto, rosa queimado, vinho/bordô e bege/off-white.

Não precisa copiar exatamente o design da referência. Queria pegar mais a identidade visual e as cores dela, mas manter uma estrutura de loja online , com produtos em destaque, categorias, ofertas, avaliações e um visual fácil de navegar.

Também quero que o site tenha duas opções bem claras para o cliente: comprar diretamente pelo site ou falar comigo pelo WhatsApp. Pode ter um botão de WhatsApp bem visível/flutuante.

A ideia é a Glow Up passar uma imagem feminina, elegante, moderna e profissional, mas sem ficar séria demais. Quero que tenha bastante destaque para os produtos e que seja fácil para a pessoa entrar, ver os produtos e comprar.
